# Contributing

Keep changes reviewable and preserve the product trust boundary: imported text
is evidence, provider output is a draft, Tool execution requires a reviewed
binding, and publication requires evaluation plus approval.

Use English for source, identifiers, errors, and authoritative documentation.
Add or update tests for every semantic change. Do not weaken a gate to make a
test pass. Run the complete development gate from `README.md` before opening a
change. Security issues should follow `SECURITY.md` rather than a public issue.
