# Security policy

ExpertCompose 0.x is an early local-first release. Report suspected
vulnerabilities privately through GitHub's security-advisory feature for this
repository. Do not attach confidential source material, credentials, or raw
workspace archives to a public issue.

The supported line is the newest tagged 0.x release. Operators remain
responsible for source rights, filesystem permissions, remote model-provider
policies, MCP authentication when exposed beyond loopback, and reviewing every
executable Tool binding.
